OS Resource Monitor

📘 About Project

Project Overview

The OS Resource Monitor and Smart Analyzer is a web-based application designed to monitor system performance in real time. It provides detailed insights into CPU usage, memory utilization, and running processes, along with intelligent suggestions for optimization.

Key Features

  • Real-time CPU and Memory monitoring
  • Process management and live process tracking
  • Smart Analyzer with system health score
  • Graph-based visualization using Chart.js
  • Alert system for high resource usage
  • Interactive and responsive UI dashboard

Technologies Used

  • Frontend: HTML, CSS, JavaScript
  • Backend: Python (Flask)
  • Library: psutil (for system data)
  • Charts: Chart.js

Objective

The objective of this project is to simulate a modern operating system monitoring tool that helps users understand system performance and take actions to optimize it effectively.
